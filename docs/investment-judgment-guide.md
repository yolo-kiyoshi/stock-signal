# 投資判断ロジック入門

対象エンジン：`rule_based_technical v2.5.0`

## この文書の目的

TOMOSHIBIYORIが、日足から何を見つけ、なぜ「購入候補」「様子見」「新規購入回避」と
表示するのかを説明します。結論を先にいうと、ダブルボトムなどのチャートパターンは
将来ずっと続くトレンドではなく、ある日に発生したシグナルです。発生後の価格を毎日
再評価し、有効期間、勢いの弱化、目標到達、失敗を区別する必要があります。

株式、ローソク足、移動平均、ATRなどの用語から学びたい場合は、先に
[はじめての株式テクニカル分析とTOMOSHIBIYORIの読み方](technical-analysis-foundations.md)を
読んでください。この文書は、基礎を理解した後に実装上の閾値と計算式を確認するリファレンスです。

画面の表示は投資助言や自動注文ではありません。手数料、税金、スリッページ、保有資産、
許容損失、企業価値を含まないため、最終判断は別に行う必要があります。

## 1. 最初に運用スタイルを選ぶ

画面では営業日数を直接選ばず、目的に合わせて次の2つから選びます。「5営業日先」は5日後に
必ず売るという意味ではなく、5営業日程度の値動きに合う短い参照窓を使うという意味です。

| 画面の選択 | 主な用途 | 想定する利用 | 方向判定の主な参照窓 |
|---|---|---|---|
| スイング・5営業日先 | 新規購入のタイミング | 数日〜数週間の値動きを狙う | 3日、5日、10日、20日 |
| 中長期の買い場・20営業日先 | 長期保有を始める前の買い場確認 | 数週間〜数か月の値動きも許容 | 10日、20日、60日 |

「中長期の買い場」は企業価値を判定するものではありません。長期投資の対象として妥当かは、業績、
財務、事業競争力、配当方針などを別に確認し、本アプリは日足による購入時期と価格リスクの確認に
限定して使います。

### 5営業日と20営業日で変わるもの

| 評価項目 | スイング（5日） | 中長期の買い場（20日） |
|---|---|---|
| 必要な日足 | 25営業日以上 | 70営業日以上 |
| 移動平均 | 5日線と20日線 | 20日線と60日線 |
| 価格モメンタム | 直近10日、±2%を方向基準 | 直近60日、±8%を方向基準 |
| 直近トレンド | 3日変動、5日平均、0.5 ATR | 10日変動、20日平均、1.0 ATR |
| RSI | 14日 | 28日 |
| 出来高の追認 | 直近3日と過去20日 | 直近10日と過去60日 |
| 安値更新の停止 | 20日安値から5営業日 | 60日安値から10営業日 |
| 仮の転換水準 | 直近10日高値 | 直近20日高値 |
| TOPIX環境 | 20日騰落率が-2%以上 | 60日騰落率が-5%以上 |
| 決算の強い警戒範囲 | 5日以内 | 5日以内（6〜20日は警告のみ） |

20日モードで短期の上向きパターンや転換初動が見つかっても、20日・60日を中心とした総合方向が
下落なら購入候補にせず「様子見」にします。これにより、一日の急反発を長期の上昇転換と誤認する
ことを抑えます。

1営業日分析は既存APIとの互換性と翌営業日のイベントリスク確認のためだけに残し、通常画面と
日次バッチの判断対象から外しています。本アプリはデイトレードや日中の売買判断には使いません。

## 2. パターンは「状態」ではなく「イベント」

ダブルボトムを例にします。

1. 近い価格帯で2回安値をつける。
2. 2つの安値の間にある高値をネックラインとする。
3. 前日終値がネックライン以下で、当日終値がネックラインを上回った日にだけ、
   上抜けイベントが発生する。
4. 翌日以降もネックラインより上にいるだけでは、同じイベントを再発生させない。

以前の実装は3の「前日から当日へ跨いだ」という条件を持たず、ネックラインより上にいる日を
繰り返し新しいパターンとして扱う余地がありました。現在はクロスした日を一度だけ記録し、
その後を独立したライフサイクル評価へ渡します。

## 3. 研究から分かること、分からないこと

Lo, Mamaysky and Wang（2000）は、米国個別株の日足に対して10種類の形を機械検出し、
パターン後のリターン分布に追加情報があるかを調べました。38営業日のローリング窓、
3営業日の検出ラグを用い、検出後の1日リターンを比較しています。重要なのは、論文自身が
「情報を含むこと」と「利益の出る売買戦略であること」は同じではない、としている点です。

Savin, Weller and Zvingelis（2007）は、S&P 500とRussell 2000のヘッド＆ショルダーズを
検証しました。単独売買戦略の収益性にはほとんど、または全く支持がない一方、市場対比の
超過リターンを予測する情報は確認したと報告しています。検証では20、40、60営業日という
固定保有期間を比較しており、「形が完成すれば無期限に有効」とは扱っていません。

したがって研究から直接「日本株のダブルボトムは5日目に買い、20日目に必ず売る」とは
結論できません。銘柄、時代、市場、取引コストによって結果が変わるためです。本アプリは、
研究で固定期間を区切って事後評価していることと、現在の主な分析期間が5、20営業日であることを
踏まえ、次の保守的な初期ルールを採用します。

| 区間・条件 | 画面表示 | 新規購入の扱い | 保有中の確認 |
|---|---|---|---|
| ブレイク当日から5営業日以内 | 新規検討期間 | 他の確認条件も満たす場合だけ購入候補 | 無効化水準と勢いを確認 |
| 6〜20営業日 | 保有監視期間 | 古いシグナルへの新規追随はしない | 目標・無効化水準を監視 |
| 20営業日超 | 期限切れ | パターンを新規判断に使わない | 現在の指標で判断し直す |
| 直近4本の逆行が0.5 ATR以上 | 勢い弱化 | 新規購入回避 | 撤退条件を確認 |
| 終値が無効化水準を越えて戻る | ブレイク失敗 | 新規購入回避 | 撤退・前提の再評価 |
| 終値が値幅目標へ到達 | 目標到達 | 新規追随を抑制 | 利益確定条件を確認 |

5営業日と20営業日は、銘柄別に最適化した値ではありません。後から結果を見て都合よく変える
過剰適合を避けるために固定した、説明可能な初期運用値です。日本株データでウォークフォワード
検証が完了したら、エンジン版を上げたうえで変更します。

## 4. 価格水準の計算

### ATR

ATRは日々の値幅を表します。値が大きく動く銘柄と小さく動く銘柄を同じ「10円」で比べず、
その銘柄の通常の値動きに対して何倍かで比較するために使います。

```text
TR = max(高値 - 安値, |高値 - 前日終値|, |安値 - 前日終値|)
初期ATR(20) = 最初の20本のTR平均
翌日以降のATR(20) = (前日のATR × 19 + 当日のTR) / 20
```

本アプリはWilder方式で平滑化します。単純な20日平均では、大きな値幅の日が20日窓から外れた
日に影響が突然ゼロになるためです。Wilder方式でも過去の影響は残りますが、日々少しずつ減衰し、
ブレイク幅や無効化水準が一日だけ不自然に飛ぶことを抑えます。パターンの目標・無効化水準には
ブレイク直前のATRを固定して使い、ブレイク後の値幅拡大で損切り基準が後から動かないようにします。

### 無効化水準

形成安値・高値と、ブレイク水準から0.5 ATR離れた水準を比較し、ノイズで狭くなりすぎない側を
採用します。さらに0.1 ATRの余裕幅を置きます。終値がこの水準を越えて戻った場合、単なる
小さな揺れではなく、ブレイクの前提が崩れた可能性として「失敗」にします。

```text
上向きの無効化水準
  = min(形成安値, ブレイク水準 - 0.5 × ATR) - 0.1 × ATR
下向きの無効化水準
  = max(形成高値, ブレイク水準 + 0.5 × ATR) + 0.1 × ATR
```

0.5 ATRはリスク管理用の初期ヒューリスティックで、上記論文が最適値を証明したものでは
ありません。画面に具体的な価格を表示し、利用者が前提を確認できるようにします。

### 値幅目標

形成期間の高値・安値とブレイク水準の距離をパターンの高さとし、上向きなら加算、下向きなら
減算します。これはチャート分析で一般的なメジャード・ムーブの考え方を機械化した参考水準です。
到達確率や利益保証ではありません。

```text
上向き目標 = ブレイク水準 + パターンの高さ
下向き目標 = ブレイク水準 - パターンの高さ
```

## 5. 勢いの弱化

ヤマハ（7951）のように、ダブルボトムの上抜け自体は正しくても、その後に価格が下向くことが
あります。本アプリはブレイク日以降の直近最大4本について、パターン方向への値動きをATRで
標準化します。

```text
上向きパターンの直近勢い = (最新終値 - 直近比較日の終値) / ATR(20)
下向きパターンの直近勢い = (直近比較日の終値 - 最新終値) / ATR(20)
```

この値が-0.5以下なら、期待方向へ0.5 ATR以上逆行したとして「勢い弱化」にします。
ネックラインを完全には割っていなくても購入候補から外し、保有中なら撤退水準を確認する表示へ
切り替えます。これにより「ダブルボトムがある」という過去の事実より、現在の値動きを優先します。

### 総合テクニカル方向

「上昇・停滞・下落」は、パターンだけでなく次の要因を合算して判定します。各参照日数は
第1節の運用スタイルによって切り替わります。

- 5日・20日平均、または20日・60日平均の位置と長期線の傾き。
- 直近10日、または60日の価格モメンタム。
- 直近3日、または10日の変動をATRで標準化した直近トレンド。
- 直近3日、または10日の値動きを裏付ける出来高。
- 発生直後のパターン、またはパターン失敗・勢い弱化の方向。

スイングでは直近3営業日で0.5 ATR以上動き、終値が5日平均と同じ方向なら30点を加えます。
中長期では直近10営業日で1.0 ATR以上動き、終値が20日平均と同じ方向なら26点を加えます。
一方、6営業日以上経過したパターンは現在方向へ加点しません。上向きパターンが勢い弱化または
失敗した場合は、過去の上昇パターンを維持せず下落要因へ切り替えます。

RSIが70を超える「買われ過ぎ」や30を下回る「売られ過ぎ」は、それだけで下落・上昇するとは
限りません。このため現在は方向へ加点せず、過熱・反発可能性の警戒情報として停滞側へ記録します。

テクニカル方向と投資検討区分は役割が異なります。例えば値動きは上昇でも、出来高不足や決算接近、
大きな窓開けがあれば投資検討区分は「様子見」です。一方、「新規購入回避」が上向きパターン後の
勢い弱化による場合は、その弱化を下落要因として総合方向にも反映します。

## 6. 上昇転換の準備度

下降している銘柄を「安い」という理由だけで購入候補にはしません。下降が止まり、短期の値動きが
改善し、転換水準へ近づいた銘柄を段階的に区別します。

```text
下降継続
  → 底固め観察
  → 転換準備
  → あと1条件
  → 転換初動
  → 上昇継続
```

`TransitionReadinessEvaluator`は次の6条件を必ず評価します。TOPIXと決算予定日が同期済みなら、
市場環境と決算までの余裕も必須条件へ追加します。

| 条件 | スイング（5日） | 中長期の買い場（20日） |
|---|---|---|
| 安値更新の停止 | 20日安値から5営業日以上 | 60日安値から10営業日以上 |
| モメンタム改善 | 5日平均と直近3日 | 20日平均と直近10日 |
| 転換水準への接近 | 水準の0.2 ATR下〜0.1 ATR上 | 同じ |
| 形成値幅の有効性 | 転換水準と形成安値の差が0.5 ATR以上 | 同じ |
| 初動出来高 | 平常時中央値の1.2倍以上 | 同じ |
| 窓開け | 当日始値の窓開けが絶対値1.5 ATR以下 | 同じ |
| 市場環境 | TOPIX 20日騰落率が-2%以上 | TOPIX 60日騰落率が-5%以上 |
| 決算までの余裕 | 次回決算まで5日超 | 次回決算まで5日超 |

ダブルボトムに近い2安値が見つかれば、その間の高値を仮ネックラインにします。見つからない場合は
スイングでは直近10日高値、中長期では直近20日高値を転換水準とします。条件が一つだけ未達なら
「あと1条件」とし、未達条件の名称、現在値、必要水準を表示します。

転換準備では、完成パターンと同じ「0.1 ATR上抜け・出来高1.5倍」を要求しません。価格が転換
水準へ近づき、出来高が1.2倍まで増えた段階を「転換初動」として先に可視化します。ただし、
この段階は購入候補ではなく様子見です。完成ブレイクは従来どおり0.1 ATR上抜けと1.5倍出来高を
別の厳しい条件として確認します。

条件進捗の`5 / 6`や準備度83.3点は、上昇確率83.3%という意味ではありません。単純に5条件を満たした
という説明用の進捗です。確率へ変換するには、各日の状態と5、20営業日後の結果を蓄積し、
未使用の将来期間で校正する必要があります。

### 転換水準、無効化水準、参考目標

転換初動では次を表示します。

```text
転換水準   = 仮ネックライン、既存パターンのブレイク水準、または期間別の直近高値
無効化水準 = min(形成安値, 転換水準 - 0.5 × ATR) - 0.1 × ATR
参考目標   = 転換水準 + (転換水準 - 形成安値)
参考R/R    = (参考目標 - 現在値) / (現在値 - 無効化水準)
```

形成値幅が0.5 ATR未満なら、目標をATRまで人工的に広げず、形状条件を未達にします。参考R/Rは
注文価格や損切り指示ではなく、同じ計算基準で候補を比較するための参考値です。形成安値を守る
保守的な無効化水準では、完成直後のR/Rが1未満になることもあります。その事実を隠さず表示し、
許容損失から購入上限株数を計算する材料にします。

### ポジションサイズ計算

画面では許容損失額を入力すると、次式で理論上限と100株単位の上限を表示します。

```text
1株あたりリスク = 現在値 - 無効化水準
理論上限株数 = floor(許容損失額 / 1株あたりリスク)
100株単位の上限 = floor(理論上限株数 / 100) × 100
```

これは購入推奨株数ではありません。手数料、スリッページ、ストップを飛び越える窓開け損失、
既存ポートフォリオとの相関を含まないため、あくまで一取引の価格リスク上限です。100株は一般的な
国内株の参考単位であり、ETFなどを含めて実際の売買単位は注文前に別途確認します。

## 7. 最終的な投資検討区分

パターンだけでは購入候補にしません。新規検討期間内で、次の条件をすべて確認します。

- パターン一致度が65点以上。
- ブレイク幅が0.1 ATR以上。
- ブレイク日の出来高が過去中央値の1.5倍以上。
- 1.5 ATRを超える大きな窓開けではない。
- 最新データが古くない。
- 決算発表予定まで5日を超えている。
- TOPIXが強い下落トレンドではない。
- パターンが勢い弱化、失敗、目標到達、期限切れではない。

完成パターンがない「転換初動」「あと1条件」「転換準備」「底固め観察」は様子見です。これにより、
ブレイク前の候補を見つけつつ、完成済みパターンと同じ購入条件を誤って適用しません。安値更新中の
「下降継続」は、下落要因が優勢なら新規購入回避です。

決算予定が6〜分析期間内にある場合は、区分を強制的に様子見へ変更せず、注意タグだけを表示します。
四半期ごとに決算がある日本株で候補が長期間枯渇することを避けながら、直前5日間のイベントリスクは
強い警戒条件として維持します。

### TOPIX相対力とベータ

TOPIXと共通する取引日から、20日または60日の相対力と単回帰ベータを計算します。

```text
相対力 = 対象株の期間騰落率 - TOPIXの期間騰落率
ベータ = Cov(対象株の日次騰落率, TOPIXの日次騰落率)
         / Var(TOPIXの日次騰落率)
```

相対力が-3%未満なら市場より弱い注意を追加します。現段階では補助情報であり、単独で購入候補を
除外しません。ベータも方向予測ではなく、市場変動に対する感応度の参考値です。

中長期の買い場では、上記を満たしても総合テクニカル方向が下落なら購入候補にしません。短期の
反発を確認した段階として「様子見」にし、20日線と60日線を中心とした方向改善を待ちます。

このうち一つでも確認できなければ、理由を画面に表示して「様子見」または「新規購入回避」へ
落とします。下降パターンは空売り指示ではなく、ロング中心の新規購入・買い増しを止める警戒です。

## 8. 今後の定量評価

初期ルールを改善するときは、未来の情報を混ぜないウォークフォワード方式を使います。

1. ある時点までのデータでパラメーターを固定する。
2. それより後の未使用期間で、5、20営業日後の絶対リターンとTOPIX超過リターンを測る。
3. パターン種別、ライフサイクル状態、出来高条件別に件数、中央値、勝率、最大逆行幅を記録する。
4. 売買手数料とスリッページを差し引く。
5. 銘柄を現在の上場銘柄だけに限定せず、可能な範囲で上場廃止銘柄を含めて生存者バイアスを抑える。
6. 検証期間を無作為分割せず、時間順を守る。

十分な件数がない条件は「良い結果」と判定しません。パラメーターを変更した場合は
`engine_version`を更新し、旧版と結果を比較できるようにします。
