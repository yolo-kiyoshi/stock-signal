# 投資判断ロジック入門

対象エンジン：`rule_based_technical v2.9.0`

## この文書の目的

TOMOSHIBIYORIが、日足から何を見つけ、なぜ「購入候補」「様子見」「新規購入回避」と
表示するのかを説明します。結論を先にいうと、ダブルボトムなどのチャートパターンは
将来ずっと続くトレンドではなく、ある日に発生したシグナルです。発生後の価格を毎日
再評価し、有効期間、勢いの弱化、目標到達、失敗を区別する必要があります。

株式、ローソク足、移動平均、ATRなどの用語から学びたい場合は、先に
[はじめての株式テクニカル分析とTOMOSHIBIYORIの読み方](technical-analysis-foundations.md)を
読んでください。この文書は、基礎を理解した後に実装上の閾値と計算式を確認するリファレンスです。

画面の表示は投資助言や自動注文ではありません。手数料、税金、スリッページ、保有資産、
許容損失、企業価値を含まないため、最終判断は別に行う必要があります。

本版では、判断を次の3層へ分けます。

1. **テクニカル方向**：価格要因が上昇・停滞・下落のどちらを向くか。
2. **形の確認**：ブレイクや押し目など、検討対象になるセットアップがあるか。
3. **今の買い準備**：現在値、損切り目安、上値余地を含め、今エントリーする条件が整ったか。

したがって「上昇」でも「押し目待ち」になり得ます。これは矛盾ではなく、良い形と良い購入価格を
区別した結果です。

## 1. 最初に運用スタイルを選ぶ

画面では営業日数を直接選ばず、目的に合わせて次の2つから選びます。「5営業日先」は5日後に
必ず売るという意味ではなく、5営業日程度の値動きに合う短い参照窓を使うという意味です。

| 画面の選択 | 主な用途 | 想定する利用 | 方向判定の主な参照窓 |
|---|---|---|---|
| スイング・5営業日先 | 新規購入のタイミング | 数日〜数週間の値動きを狙う | 3日、5日、10日、20日 |
| 中長期の買い場・20営業日先 | 長期保有を始める前の買い場確認 | 数週間〜数か月の値動きも許容 | 10日、20日、60日 |

「中長期の買い場」は企業価値を判定するものではありません。長期投資の対象として妥当かは、業績、
財務、事業競争力、配当方針などを別に確認し、本アプリは日足による購入時期と価格リスクの確認に
限定して使います。

### 5営業日と20営業日で変わるもの

| 評価項目 | スイング（5日） | 中長期の買い場（20日） |
|---|---|---|
| 必要な日足 | 25営業日以上 | 70営業日以上 |
| 移動平均 | 5日線と20日線 | 20日線と60日線 |
| 価格モメンタム | 直近10日、±2%を方向基準 | 直近60日、±8%を方向基準 |
| 直近トレンド | 3日変動、5日平均、0.5 ATR | 10日変動、20日平均、1.0 ATR |
| RSI | 14日 | 28日 |
| 出来高の追認 | 直近3日と過去20日 | 直近10日と過去60日 |
| 安値更新の停止 | 20日安値から5営業日 | 60日安値から10営業日 |
| 仮の転換水準 | 直近10日高値 | 直近20日高値 |
| TOPIX環境 | 20日騰落率が-2%以上 | 60日騰落率が-5%以上 |
| 決算の強い警戒範囲 | 5日以内 | 5日以内（6〜20日は警告のみ） |

20日モードは、スイングと同じ完成ブレイクをそのまま購入条件にはしません。20日・60日線を中心に
中期上昇トレンドが保たれているかを先に確認し、その中で移動平均、直近20日安値、上抜け後の
旧抵抗帯へ価格が戻った「押し目」を別に評価します。総合方向が下落なら、安値に触れただけで
購入候補にしません。

1営業日分析は既存APIとの互換性と翌営業日のイベントリスク確認のためだけに残し、通常画面と
日次バッチの判断対象から外しています。本アプリはデイトレードや日中の売買判断には使いません。

### チャートへ重ねる補助指標

運用スタイルを切り替えると、判断ルールと同じ期間設定で補助指標を表示します。

| 運用スタイル | 移動平均 | RSI | 抵抗帯の参照範囲 |
|---|---|---|---|
| スイング | 5日・20日単純移動平均 | Wilder RSI 14日 | 過去60営業日 |
| 中長期の買い場 | 20日・60日単純移動平均 | Wilder RSI 28日 | 過去120営業日 |

移動平均とRSIは分析エンジンとチャートで同じ共通関数を使います。表示期間より前の保存済み日足を
計算の助走期間に含め、APIでは表示日と同じ長さへ揃えた配列を返します。これにより、1か月表示の
先頭で60日平均が欠けることを防ぎます。未来の日足は計算へ混ぜません。

抵抗帯は次の説明可能な初期規則で求めます。

1. 選択スタイルの参照範囲から、前後2営業日より高い局所高値を抽出する。
2. 価格差が0.5 ATR以内の局所高値を同じグループへまとめる。
3. 2回以上接触したグループだけを候補とし、中心から最低0.2 ATRの幅を持つ帯にする。
4. 現在終値が上端を0.1 ATRより明確に上回った帯は、現在の抵抗候補から除く。
5. 現在値に近いものから最大3件を描画する。

局所高値は後続2営業日を見て確定するため、直近2本は抵抗帯の接触点になりません。これは過去の
抵抗候補を見やすくする表示機能で、パターン検出器のネックラインや購入候補条件を置き換えません。
抵抗帯があるから反落する、RSIが70を超えたから売る、という単独判断には使用しません。各指標の
チェックを外しても表示だけが変わり、日次分析結果や保存データは変わりません。

### AI最終確認の位置づけ

AI最終確認は、ここまでのテクニカル判定を再計算するエンジンではありません。選択した銘柄、
運用スタイル、日足基準日、方向スコア、判定要因、チャートパターン、決算やTOPIXの確認状態を
固定したうえで、OpenAIのWeb検索により次を追加確認します。

1. 会社IR、TDnet、取引所、官公庁などの最新の一次情報。
2. 一次情報だけでは分からない場合の、信頼できる関連報道。
3. テクニカル判断を支持する材料と、矛盾させる材料。
4. 決算、業績修正、増資、M&A、規制、事故などの主要リスク。
5. 検索しても確認できなかった事項。

AIの出力区分は「検討継続」「保留」「新規購入見送り」です。「検討継続」は購入指示ではなく、
次の確認へ進めるという意味です。AIは利用者の総資金、許容損失、税務、他の保有銘柄を知らないため、
購入・売却・株数を断定させません。また、テクニカルの判定スコアを上昇確率へ変換させません。

検索結果には誤情報、古い記事、銘柄名の取り違えが含まれる可能性があります。画面には日足基準日、
調査日時、使用モデル、引用元を表示し、重要な事実はリンク先の一次情報で再確認します。引用のない
主張や「未確認」は判断根拠へ採用しません。この層は将来も自動注文へ直接接続せず、検証済みの
定量ルールとリスク上限を別の必須条件とします。

AI回答は全体を日本語2,000文字程度に抑える指示を出し、API側の出力上限は既定6,000トークンと
します。Responses APIの出力上限には表示文章だけでなく推論トークンも含まれます。上限到達で
`incomplete`になった場合、途中の文章を最終判断として表示せずエラーにします。上限は
`OPENAI_MAX_OUTPUT_TOKENS`で2,000〜20,000の範囲に変更できますが、増加は料金と待ち時間にも
影響するため、まず簡潔な出力を維持します。

## 2. パターンは「状態」ではなく「イベント」

ダブルボトムを例にします。

1. 近い価格帯で2回安値をつける。
2. 2つの安値の間にある高値をネックラインとする。
3. 前日終値がネックライン以下で、当日終値がネックラインを上回った日にだけ、
   上抜けイベントが発生する。
4. 翌日以降もネックラインより上にいるだけでは、同じイベントを再発生させない。

以前の実装は3の「前日から当日へ跨いだ」という条件を持たず、ネックラインより上にいる日を
繰り返し新しいパターンとして扱う余地がありました。現在はクロスした日を一度だけ記録し、
その後を独立したライフサイクル評価へ渡します。

日足のダブルボトムとダブルトップは、2つの安値または高値が最低10営業日、最大35営業日離れて
いる場合だけ検出します。数日間の小さなW字を中期的な反転形状と誤認しないためです。また、
ダブルボトムは形成前のトレンドスコアが負、ダブルトップは正の場合だけ反転パターンとします。
すでに上昇中に現れたW字は上昇途中の持ち合いである可能性があるため、ダブルボトム反転として
購入候補へ加点しません。10日と35日は説明可能な初期値であり、成功確率を保証する最適値では
ありません。

## 3. 研究から分かること、分からないこと

Lo, Mamaysky and Wang（2000）は、米国個別株の日足に対して10種類の形を機械検出し、
パターン後のリターン分布に追加情報があるかを調べました。38営業日のローリング窓、
3営業日の検出ラグを用い、検出後の1日リターンを比較しています。重要なのは、論文自身が
「情報を含むこと」と「利益の出る売買戦略であること」は同じではない、としている点です。

Savin, Weller and Zvingelis（2007）は、S&P 500とRussell 2000のヘッド＆ショルダーズを
検証しました。単独売買戦略の収益性にはほとんど、または全く支持がない一方、市場対比の
超過リターンを予測する情報は確認したと報告しています。検証では20、40、60営業日という
固定保有期間を比較しており、「形が完成すれば無期限に有効」とは扱っていません。

Brock, Lakonishok and LeBaron（1992）は、ダウ平均の長期データで移動平均ルールと
トレーディングレンジ・ブレイクを検証し、売買シグナル後のリターン分布に差を報告しました。
ただし、Urquhart, Gebka and Hudson（2015）はダウ、FT30、TOPIXの1987年以降を調べ、
移動平均ルールの予測力が3市場で消失または低下したと報告しています。単純な移動平均ルールを
永続的な利益法則として扱えないことを示す重要な反証です。

Zapranis and Tsinaslanidis（2012）は、NYSE・NASDAQ個別株の日足から水平支持・抵抗を
ルールベースで抽出しました。支持水準は抵抗水準よりトレンド中断の予測に優れた一方、単純な
買い持ちと比べた超過収益は生まれなかったと報告しています。したがって本アプリは、支持帯への
接触を「買いの証明」ではなく、反発を確認する場所の候補としてのみ使います。

したがって研究から直接「日本株のダブルボトムは5日目に買い、20日目に必ず売る」とは
結論できません。銘柄、時代、市場、取引コストによって結果が変わるためです。本アプリは、
研究で固定期間を区切って事後評価していることと、現在の主な分析期間が5、20営業日であることを
踏まえ、次の保守的な初期ルールを採用します。

| 区間・条件 | 画面表示 | 新規購入の扱い | 保有中の確認 |
|---|---|---|---|
| ブレイク当日から3営業日以内 | 新規検討期間 | 価格位置を含む他の条件も満たす場合だけ購入候補 | 無効化水準と勢いを確認 |
| 4〜20営業日 | 保有監視期間 | 古いシグナルへの新規追随はしない | 目標・無効化水準を監視 |
| 20営業日超 | 期限切れ | パターンを新規判断に使わない | 現在の指標で判断し直す |
| 転換水準から1.0 ATR超、または想定値幅を50%以上消化 | 上昇追随回避 | 購入候補から様子見へ変更 | 押し目と残存余地を確認 |
| 直近3営業日で2.5 ATR超、または5日線から1.5 ATR超 | 急伸・高値追い回避 | 新規追随をせず押し目待ち | 値動きの沈静化を確認 |
| 実行用R/Rが1.2未満 | 上値余地不足 | スイング購入候補から様子見へ変更 | 損切りと目標の再評価 |
| 直近4本の逆行が0.5 ATR以上 | 勢い弱化 | 新規購入回避 | 撤退条件を確認 |
| 終値が無効化水準を越えて戻る | ブレイク失敗 | 新規購入回避 | 撤退・前提の再評価 |
| 終値が値幅目標へ到達 | 目標到達 | 新規追随を抑制 | 利益確定条件を確認 |

3営業日と20営業日は、銘柄別に最適化した値ではありません。後から結果を見て都合よく変える
過剰適合を避けるために固定した、説明可能な初期運用値です。日本株データでウォークフォワード
検証が完了したら、エンジン版を上げたうえで変更します。

### 新規追随を避ける価格位置

日数が短くても、ブレイク当日に大きく上昇した場合や、数日で目標近くまで進んだ場合があります。
そのため、新規検討期間は日数だけで決めません。

```text
転換水準からの距離 = パターン方向の（最新終値 - 転換水準）/ ブレイク時ATR
想定値幅の消化率 = パターン方向の（最新終値 - 転換水準）/ パターンの高さ
構造R/R = 目標までの残り値幅 / 構造的無効化水準までの値幅
実行用損切り目安 = max(構造的無効化水準, 転換水準 - 0.5 × ATR)  # 上向き
実行用R/R = 目標までの残り値幅 / 実行用損切り目安までの値幅
```

距離、値幅消化率、3日急伸、5日線乖離のいずれかが基準を超えた場合は「押し目待ち」として
購入候補から外します。形成安値を使う構造R/Rはパターン全体の失敗を測るため遠くなりやすく、
新規購入の価格評価には向きません。そのため、実行時は転換水準の0.5 ATR下と構造的無効化水準の
高い側を終値基準の損切り目安とし、実行用R/Rが1.2以上あることを確認します。これらは自動注文価格
ではなく、窓開け時には想定より不利な価格で約定し得ます。

## 4. 価格水準の計算

### ATR

ATRは日々の値幅を表します。値が大きく動く銘柄と小さく動く銘柄を同じ「10円」で比べず、
その銘柄の通常の値動きに対して何倍かで比較するために使います。

```text
TR = max(高値 - 安値, |高値 - 前日終値|, |安値 - 前日終値|)
初期ATR(20) = 最初の20本のTR平均
翌日以降のATR(20) = (前日のATR × 19 + 当日のTR) / 20
```

本アプリはWilder方式で平滑化します。単純な20日平均では、大きな値幅の日が20日窓から外れた
日に影響が突然ゼロになるためです。Wilder方式でも過去の影響は残りますが、日々少しずつ減衰し、
ブレイク幅や無効化水準が一日だけ不自然に飛ぶことを抑えます。パターンの目標・無効化水準には
ブレイク直前のATRを固定して使い、ブレイク後の値幅拡大で損切り基準が後から動かないようにします。

### 無効化水準

形成安値・高値と、ブレイク水準から0.5 ATR離れた水準を比較し、ノイズで狭くなりすぎない側を
採用します。さらに0.1 ATRの余裕幅を置きます。終値がこの水準を越えて戻った場合、単なる
小さな揺れではなく、ブレイクの前提が崩れた可能性として「失敗」にします。

```text
上向きの無効化水準
  = min(形成安値, ブレイク水準 - 0.5 × ATR) - 0.1 × ATR
下向きの無効化水準
  = max(形成高値, ブレイク水準 + 0.5 × ATR) + 0.1 × ATR
```

0.5 ATRはリスク管理用の初期ヒューリスティックで、上記論文が最適値を証明したものでは
ありません。画面に具体的な価格を表示し、利用者が前提を確認できるようにします。

### 値幅目標

形成期間の高値・安値とブレイク水準の距離をパターンの高さとし、上向きなら加算、下向きなら
減算します。これはチャート分析で一般的なメジャード・ムーブの考え方を機械化した参考水準です。
到達確率や利益保証ではありません。

```text
上向き目標 = ブレイク水準 + パターンの高さ
下向き目標 = ブレイク水準 - パターンの高さ
```

## 5. 勢いの弱化

ヤマハ（7951）のように、ダブルボトムの上抜け自体は正しくても、その後に価格が下向くことが
あります。本アプリはブレイク日以降の直近最大4本について、パターン方向への値動きをATRで
標準化します。

```text
上向きパターンの直近勢い = (最新終値 - 直近比較日の終値) / ATR(20)
下向きパターンの直近勢い = (直近比較日の終値 - 最新終値) / ATR(20)
```

この値が-0.5以下なら、期待方向へ0.5 ATR以上逆行したとして「勢い弱化」にします。
ネックラインを完全には割っていなくても購入候補から外し、保有中なら撤退水準を確認する表示へ
切り替えます。これにより「ダブルボトムがある」という過去の事実より、現在の値動きを優先します。

### 総合テクニカル方向

「上昇・停滞・下落」は、パターンだけでなく次の要因を合算して判定します。各参照日数は
第1節の運用スタイルによって切り替わります。

- 5日・20日平均、または20日・60日平均の位置と長期線の傾き。
- 直近10日、または60日の価格モメンタム。
- 直近3日、または10日の変動をATRで標準化した直近トレンド。
- 直近3日、または10日の値動きを裏付ける出来高。
- 発生直後のパターン、またはパターン失敗・勢い弱化の方向。

スイングでは直近3営業日で0.5 ATR以上動き、終値が5日平均と同じ方向なら30点を加えます。
中長期では直近10営業日で1.0 ATR以上動き、終値が20日平均と同じ方向なら26点を加えます。
一方、6営業日以上経過したパターンは現在方向へ加点しません。上向きパターンが勢い弱化または
失敗した場合は、過去の上昇パターンを維持せず下落要因へ切り替えます。

RSIが70を超える「買われ過ぎ」や30を下回る「売られ過ぎ」は、それだけで下落・上昇するとは
限りません。このため現在は方向へ加点せず、過熱・反発可能性の警戒情報として停滞側へ記録します。

テクニカル方向と投資検討区分は役割が異なります。例えば値動きは上昇でも、出来高不足や決算接近、
大きな窓開けがあれば投資検討区分は「様子見」です。一方、「新規購入回避」が上向きパターン後の
勢い弱化による場合は、その弱化を下落要因として総合方向にも反映します。

## 6. 上昇転換の準備度

下降している銘柄を「安い」という理由だけで購入候補にはしません。下降が止まり、短期の値動きが
改善し、転換水準へ近づいた銘柄を段階的に区別します。

```text
下降継続
  → 底固め観察
  → 転換準備
  → あと1条件
  → 転換初動
  → 上昇継続
```

`TransitionReadinessEvaluator`は次の6条件を必ず評価します。TOPIXと決算予定日が同期済みなら、
市場環境と決算までの余裕も必須条件へ追加します。

| 条件 | スイング（5日） | 中長期の買い場（20日） |
|---|---|---|
| 安値更新の停止 | 20日安値から5営業日以上 | 60日安値から10営業日以上 |
| モメンタム改善 | 5日平均と直近3日 | 20日平均と直近10日 |
| 転換水準への接近 | 水準の0.2 ATR下〜0.1 ATR上 | 同じ |
| 形成値幅の有効性 | 転換水準と形成安値の差が0.5 ATR以上 | 同じ |
| 初動出来高 | 平常時中央値の1.2倍以上 | 同じ |
| 窓開け | 当日始値の窓開けが絶対値1.5 ATR以下 | 同じ |
| 市場環境 | TOPIX 20日騰落率が-2%以上 | TOPIX 60日騰落率が-5%以上 |
| 決算までの余裕 | 次回決算まで5日超 | 次回決算まで5日超 |

### 寄り付き前の外部市場環境

TOPIXの20日・60日騰落率は、日本市場の中期的な地合いを確認する指標です。しかし、前夜に
米国株、原油、金利が急変した場合、前日までのTOPIXだけでは当日のショックを捉えられません。
そこでTOMOSHIBIYORIは、東京市場が始まる前の08:30 JSTを基準に、次を別レイヤーで評価します。

| 構成要因 | 初期の警戒条件 | 最大点 |
|---|---|---:|
| 米国株 | SPY・QQQの弱い方が-0.5%、-1%、-2%以下 | 30 |
| 原油 | WTIが+1.5%、+3%、+5%以上 | 25 |
| 米国金利 | 米10年債利回りが+2、+5、+10bp以上 | 25 |
| 為替 | USD/JPYの絶対変化率が0.8%、1.5%以上 | 10 |

合計25点以上を「警戒」、50点以上を「強い警戒」とします。米国株のSPYとQQQは同じ要因を
二重加点せず、弱い方を一つの「米国株」要因として扱います。観測日が4暦日を超えて古い値は
除外し、5指標の40%未満しか取得できなければ「未評価」とします。

この点数は確率ではなく、固定ルールに何項目該当したかをまとめた警戒スコアです。外部環境が
「強い警戒」でも、個別銘柄のチャートが上向きならテクニカル方向は「上昇」のままです。ただし、
新規の購入候補は「様子見・条件付き候補」へ変更し、購入延期または株数縮小の確認を促します。
既に保有している銘柄を自動的に売却する条件にはしません。

```text
現在のテクニカル方向：上昇
寄り付き前の外部環境：強い警戒
最終的な新規購入判断：様子見
```

地政学ニュースの文章だけで点数を決めると、表現の違いや誤報で判定が不安定になります。そのため、
初期版では数値化できる市場反応を判定の本体とし、ニュース検索は「なぜ原油や金利が動いたか」を
説明する補助情報として扱います。

ダブルボトムに近い2安値が見つかれば、その間の高値を仮ネックラインにします。見つからない場合は
スイングでは直近10日高値、中長期では直近20日高値を転換水準とします。条件が一つだけ未達なら
「あと1条件」とし、未達条件の名称、現在値、必要水準を表示します。

転換準備では、完成パターンと同じ「0.1 ATR上抜け・出来高1.5倍」を要求しません。価格が転換
水準へ近づき、出来高が1.2倍まで増えた段階を「転換初動」として先に可視化します。ただし、
この段階は購入候補ではなく様子見です。完成ブレイクは従来どおり0.1 ATR上抜けと1.5倍出来高を
別の厳しい条件として確認します。

条件進捗の達成率は、上昇確率という意味ではありません。単純に必要条件のうち何件を満たしたかを示す
説明用の進捗です。確率へ変換するには、各日の状態と5、20営業日後の結果を蓄積し、
未使用の将来期間で校正する必要があります。

### 転換水準、無効化水準、参考目標

転換初動では次を表示します。

```text
転換水準   = 仮ネックライン、既存パターンのブレイク水準、または期間別の直近高値
無効化水準 = min(形成安値, 転換水準 - 0.5 × ATR) - 0.1 × ATR
参考目標   = 転換水準 + (転換水準 - 形成安値)
参考R/R    = (参考目標 - 現在値) / (現在値 - 無効化水準)
```

形成値幅が0.5 ATR未満なら、目標をATRまで人工的に広げず、形状条件を未達にします。参考R/Rは
注文価格や損切り指示ではなく、同じ計算基準で候補を比較するための参考値です。形成安値を守る
保守的な無効化水準では、完成直後のR/Rが1未満になることもあります。その事実を隠さず表示し、
許容損失から購入上限株数を計算する材料にします。

### ポジションサイズ計算

画面では許容損失額を入力すると、次式で理論上限と100株単位の上限を表示します。

```text
1株あたりリスク = 現在値 - 実行用損切り目安
理論上限株数 = floor(許容損失額 / 1株あたりリスク)
100株単位の上限 = floor(理論上限株数 / 100) × 100
```

これは購入推奨株数ではありません。手数料、スリッページ、ストップを飛び越える窓開け損失、
既存ポートフォリオとの相関を含まないため、あくまで一取引の価格リスク上限です。100株は一般的な
国内株の参考単位であり、ETFなどを含めて実際の売買単位は注文前に別途確認します。

## 7. 中長期ポジションの押し目評価

中長期の買い場では、スイングの「上抜け直後を追う」評価とは別に、上昇トレンド中の一時的な
下落が支持候補で止まり、反発し始めたかを評価します。安値で買うこと自体を目的にすると、下降中の
銘柄を早過ぎる段階で買う危険があるため、次の6条件を順番に確認します。

| 条件 | 初期ルール | 意味 |
|---|---|---|
| 移動平均の順序 | 20日線が60日線以上 | 中期の価格水準が長期平均を上回る |
| 長期線の傾き | 60日線が5営業日前より上 | 長期平均自体が上向き |
| 中期トレンド維持 | 終値が60日線-0.5 ATR以上 | 単なる安値ではなく上昇前提を維持 |
| 支持候補の維持 | 候補帯へ接触し、終値が帯下端以上 | 日中の接触と終値割れを区別 |
| 反発確認 | 前日終値を上回る陽線で、値幅上側40%に引ける | 接触当日の下げ止まりだけで買わない |
| 参加者の確認 | 出来高が過去中央値の0.8倍以上、または2日続伸で0.5 ATR以上 | 薄い反発をそのまま買わない |

支持候補は次の価格から作ります。移動平均や安値を一本の正確な価格とみなさず、中心から
±0.35 ATRの帯として評価します。

1. 20日単純移動平均。
2. 60日単純移動平均。
3. 当日を除く直近20営業日の安値。
4. 過去120営業日で局所高値が2回以上集中し、その後0.35 ATRより明確に上抜けた旧抵抗帯。

支持帯への接触は当日だけでなく直近3営業日までを有効とし、何日前の接触かを記録します。上記6条件を
満たした場合だけ「押し目反発を確認」とし、データ鮮度、決算直前5日、TOPIX環境、60日相対力、
直近20日相対力を確認します。直近20日相対力がTOPIX比-3%未満、または直近の上値抵抗までの
実行用R/Rが1.5未満・算出不能なら、反発形状があっても「条件付き候補」として様子見にします。
支持候補に触れたが反発を確認できない場合は
「支持候補を試す」、1 ATR以内へ近づいただけなら「支持候補へ接近」、20日線から1.5 ATR以上
上に離れていれば「支持帯から上方乖離」として様子見にします。

参考無効化水準は、実際に接触して維持した支持帯の下端からさらに0.5 ATR下です。これは注文を
自動生成する損切り価格ではなく、押し目という前提が崩れる水準を比較するための初期値です。
各倍率は上記研究が日本株で最適と証明した値ではないため、過去当てはめとウォークフォワード検証で
別途評価します。

条件進捗の`5 / 6`などの達成率も将来確率ではありません。「何を待っているか」を説明するための単純な
達成率です。

## 8. 最終的な投資検討区分

スイングではパターンだけで購入候補にしません。新規検討期間内で、次の条件をすべて確認します。

- パターン一致度が65点以上。
- ブレイク幅が0.1 ATR以上。
- ブレイク日の出来高が過去中央値の1.5倍以上。
- 1.5 ATRを超える大きな窓開けではない。
- 最新データが古くない。
- 決算発表予定まで5日を超えている。
- TOPIXが強い下落トレンドではない。
- パターンが勢い弱化、失敗、目標到達、期限切れではない。
- ブレイクから3営業日以内である。
- 転換水準から1.0 ATR以内で、想定値幅の消化率が50%未満である。
- 直近3営業日の上昇が2.5 ATR以下で、5日線からの乖離が1.5 ATR以下である。
- 転換水準基準の実行用R/Rが1.2以上である。

完成パターンがない「転換初動」「あと1条件」「転換準備」「底固め観察」は様子見です。これにより、
ブレイク前の候補を見つけつつ、完成済みパターンと同じ購入条件を誤って適用しません。安値更新中の
「下降継続」は、下落要因が優勢なら新規購入回避です。

決算予定が6〜分析期間内にある場合は、区分を強制的に様子見へ変更せず、注意タグだけを表示します。
四半期ごとに決算がある日本株で候補が長期間枯渇することを避けながら、直前5日間のイベントリスクは
強い警戒条件として維持します。

### TOPIX相対力とベータ

TOPIXと共通する取引日から、20日または60日の相対力と単回帰ベータを計算します。

```text
相対力 = 対象株の期間騰落率 - TOPIXの期間騰落率
ベータ = Cov(対象株の日次騰落率, TOPIXの日次騰落率)
         / Var(TOPIXの日次騰落率)
```

相対力が-3%未満なら市場より弱い注意を追加します。中長期では直近20日相対力が-3%未満の場合、
反発の継続を待つため購入候補を条件付きへ落とします。ベータは方向予測ではなく、市場変動に対する
感応度の参考値です。

中長期の買い場は上記のブレイク条件ではなく、第7節の押し目5条件を使います。直近に上向き
パターンがあっても、支持候補から大きく上方へ離れていれば追随購入を急がず様子見にします。
一方、下降パターンが有効な間は、押し目条件より下降警戒を優先します。

このうち一つでも確認できなければ、理由を画面に表示して「様子見」または「新規購入回避」へ
落とします。下降パターンは空売り指示ではなく、ロング中心の新規購入・買い増しを止める警戒です。

## 9. 過去当てはめ実績レポート

`historical-report`は、指定期間の各取引日に本アプリを使っていたら何と判定したかを再現し、実際の
値動きとまとめて照合する単独HTMLレポートです。ダッシュボードには表示せず、保存済み日足を使う
一回実行型CLIとして分離します。判定処理へ渡す入力は基準日以前の日足と、同じ時点までのTOPIX
日足に切り詰めます。基準日より後の日足は判定が完了した後にだけ実績計算へ使います。

期間内に保存されている各取引日を基準日とします。判定日の終値で都合よく約定できたとは仮定せず、
翌営業日の始値をエントリー価格とします。実績日は基準日の翌日を1営業日目として、5番目と20番目の
取引日です。必要な過去履歴または将来実績がない行は詳細表から除外し、除外件数を
レポートへ表示します。期間未指定時は保存済み最新日から直近1年を対象にします。

実績方向は、異なる価格帯・値動きの銘柄を同じ基準で比較するため、判定日時点のWilder ATR(20)で
終値変化を割って分類します。将来日の高値・安値からATRを再計算しません。

```text
実績ATR変化 = (実績日終値 - 翌営業日始値) / 判定日時点ATR(20)

スイング（5営業日）
  +0.5 ATR以上 = 上昇
  -0.5 ATR以下 = 下落
  その間         = 停滞

中長期（20営業日）
  +1.0 ATR以上 = 上昇
  -1.0 ATR以下 = 下落
  その間         = 停滞
```

レポートは判定日ごとにスイングと中長期を横並びにし、当時のテクニカル方向、投資検討区分、
実績方向、実績日、方向の一致・不一致、騰落率、ATR換算値を表示します。購入候補が連日続く場合は
初日だけを一つの「購入イベント」として集計し、保有期間中の最大上昇率（MFE）、最大逆行率（MAE）、
参考目標・実行用損切りへの到達も表示します。同じ日に双方へ触れた場合は日足だけでは順序が分からない
ため、保守的に損切りが先と扱います。方向の一致は
`up / flat / down`同士を比べます。「購入候補」と「上昇」は異なる出力なので、投資検討区分
そのものの正誤とは扱いません。

現在の`earnings_calendar`は将来予定の最新スナップショットであり、各過去日に当時公表済みだった
決算予定を履歴保存していません。後から得た予定を過去判定へ入れると未来情報になるため、過去時点
検証では決算までの日数を明示的に未評価にします。この制約により、当時の画面表示を完全に複製する
ものではなく、価格・出来高・当時までのTOPIXによる再現です。また、株価は現在DBに保存されている
最新の遡及調整済み系列を使います。各過去日に配信されていたデータスナップショットそのものでは
ありません。

レポートの方向一致率は、指定銘柄・指定期間に現在のエンジン版を過去適用した3分類の一致割合です。
銘柄や期間を見てから都合よく選べるため、売買戦略の勝率や将来性能とは扱いません。手法全体の評価
には、対象母集団、期間、エンジン版、取引コストを事前固定する次節のウォークフォワード検証が
必要です。

```bash
docker compose run --rm app stock-signal historical-report 7203 \
  --from 2024-01-01 --to 2025-12-31 --output-dir /app/reports
```

## 10. 今後の定量評価

初期ルールを改善するときは、未来の情報を混ぜないウォークフォワード方式を使います。

1. ある時点までのデータでパラメーターを固定する。
2. それより後の未使用期間で、5、20営業日後の絶対リターンとTOPIX超過リターンを測る。
3. パターン種別、ライフサイクル状態、出来高条件別に件数、中央値、勝率、最大逆行幅を記録する。
4. 売買手数料とスリッページを差し引く。
5. 銘柄を現在の上場銘柄だけに限定せず、可能な範囲で上場廃止銘柄を含めて生存者バイアスを抑える。
6. 検証期間を無作為分割せず、時間順を守る。

十分な件数がない条件は「良い結果」と判定しません。パラメーターを変更した場合は
`engine_version`を更新し、旧版と結果を比較できるようにします。
