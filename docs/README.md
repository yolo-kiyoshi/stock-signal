## 理論的背景

[テクニカル分析の理論的背景](technical-analysis-foundations.md)では、価格・出来高、移動平均、
RSI、ATR、支持・抵抗、相対力、リスク指標と検証上の限界を説明する。
個々のルールの式と根拠は[分析ロジック](investment-judgment-guide.md)に記載する。
参考文献の一般的な知見は、本アプリの閾値や収益性を実証したものではない。
