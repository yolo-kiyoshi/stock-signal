# 購入区分・チャート判定の監査（2026年9月6日）

対象は日足のスイング・中長期分析。エンジンを2.10.0へ更新した。購入候補ゼロは条件次第で正常だが、データ不足による保留とは区別する必要がある。以下は分析情報の整合性を改善する変更であり、将来の収益改善や的中率を確認したものではない。

## 修正した問題

| 項目 | 問題 | 修正 |
|---|---|---|
| 全市場の財務 | ウォッチ・保有しか同期せず、未登録の中長期候補が財務未取得で保留される | 両期間のテクニカル通過銘柄を抽出し、必要銘柄だけ財務を追加取得して最終判定 |
| 商品区分 | マスタの非公式項目を参照し、ETF等が普通株扱いになる | 公式のProdCatを読む。企業財務を前提とする市場スクリーニングは普通株に限定 |
| 判定の説明 | 財務不足の説明がテクニカル条件未達の説明まで置き換える | 元の条件不成立理由を保持。テクニカル通過・最終候補・財務確認待ち・リスク保留を区別 |
| 更新途中の一覧 | 削除と挿入の間に候補が一時的にゼロになる | 両期間のスナップショットを同じトランザクションで置換。失敗時は旧結果を維持 |
| 形状の目標値 | 検出時とは異なる期間の高安を使い、無関係な極値で目標が膨らむ | 検出した形成期間と高さを保存し、目標・無効化水準の計算に使う |
| パターンの有効性 | 途中で失敗・目標到達しても、価格が戻ると再び初期購入期間に見える | 確認翌日から順に履歴を追い、最初の終了状態を保持 |
| 三角持ち合い | 水平側の接触確認と上昇・下降の対応が逆 | 上昇三角は上側、下降三角は下側の接触回数を確認 |
| 三尊・逆三尊 | 傾いたネックラインを水平平均で扱う。反転前の方向確認がない | 2点のネックラインを当日・前日に延長して交差を判定。三尊は事前上昇、逆三尊は事前下降を要求 |
| 支持帯 | 途中の終値割れを無視し、回復だけで支持維持とする | 接触前の位置と接触後の全終値を確認。割れた支持帯を維持済みと扱わない |
| 安値安定 | 同じ安値を再度付けても最初の安値から日数を数える | 最後に安値を付けた日から数える |
| 抵抗帯と上値余地 | 抵抗帯の中央までを利益余地として使う | 手前側までで計算し、現在値が抵抗帯内なら目標を未算出 |
| 現在の売買条件 | 過去のブレイク日の出来高・窓開けだけで通過する | 現在足の出来高ゼロ、前日までのATRに対する窓開け1.5倍超、確認不能を保留 |
| 損切りと目標 | 損切りが現在値以上、目標不足でも購入区分が残り得る | 損切り＜現在値＜目標を必須にし、実行用リワード／リスクをスイング1.2以上・中長期1.5以上と照合 |
| 値幅のない日足 | ATRゼロで中長期分析が例外終了する | 分析不足として返し、銘柄全体の処理を止めない。パターンリスクへ架空のATRを代入しない |
| 会社予想 | 配当修正で業績予想が消える。変更なしの後続開示で下方修正警告が消える | 業績予想の書類・対象年度を区別し、下方修正イベントは30日保持 |

## 判定の意味と未検証の点

- パターンの失敗は構造的な無効化水準に対する**終値**で判定する。目標到達は翌日以降の高安を使う。同じ日足で両方を満たした場合は失敗を優先する保守的な分類で、約定順序の再現ではない。実行用損切りと構造的な無効化水準も別物である。
- 日足で分かるのは前営業日までの状態。現在足の出来高が正でも、翌日の約定・スプレッド・売買停止を保証しない。
- 支持帯の維持は現在の候補価格帯に対する直近足の位置関係である。過去時点の移動平均を逐次追跡した売買シミュレーションではない。
- 形状検出は直近30営業日の形成と25営業日の検出探索が中心で、直近の成立日を採用する。長期の大型形状、未完成形状、ウェッジ・フラッグ等を網羅する仕様ではない。
- SMA・RSI・ATR、出来高、抵抗帯、TOPIX比較、決算予定、上昇転換・押し目・ブレイク後確認の既存ルールを維持する。指標やパターンを追加するだけで精度が上がるとは扱わない。
- RSI水準、接触許容幅、最低リワード／リスク、PER40倍等はルール上の確認水準。業種別・時期別の検証で裏付けた最適値ではない。銀行など営業利益が提供されない銘柄は財務確認待ちが残り得る。
- 既存の過去検証はテクニカルの検証。今回の財務・保有制約を含む最終区分の実績と混同しない。コスト控除後、最大逆行、対TOPIX超過、候補数を時系列で比較するまでは収益改善を主張しない。

## 検証

Docker Compose内でpytest、ruff check .、画面の型検査、ESLintを実行した。形成範囲、終了状態の保持、無効な損切り、最新日の出来高・ギャップ、再安値、ATRゼロ、支持割れ、会社予想の履歴、商品区分、二段階同期、保存失敗のロールバックを回帰テストで確認する。

## 実データでの確認

`make update`と`make start`を実行した。9月4日の日足に対し、スイング500銘柄で購入候補1件、中長期496銘柄で購入候補1件・財務確認待ち1件。テクニカル通過の3銘柄を追加同期し、取得失敗は0件だった。財務確認待ちは修正再表示・連結範囲変更による単純比較の保留であり、未取得とは異なる。テスト195件、ruff、型検査、ESLintは成功した。
