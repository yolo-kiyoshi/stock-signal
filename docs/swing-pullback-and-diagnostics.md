# スイング押し目反発と候補一覧の価格位置

## 目的

ブレイク追随と押し目反発を分け、候補一覧で中期的な上昇の進み具合、抵抗までの余地、損切り幅を比較できるようにする。表示は日足基準日の分析情報であり、リアルタイムの購入価格や将来確率ではない。

既存のブレイク条件と中長期の押し目条件は維持する。価格位置指標の表示だけでは、従来のブレイク候補を過熱理由で自動除外しない。

## 候補一覧と詳細の指標

すべて同じ分析基準日の終値を使う。ATRは既存のWilder ATR(20)。

| 指標 | 計算・意味 |
|---|---|
| 20日線乖離率 | `(終値 / SMA20 - 1) × 100` |
| 20日線乖離ATR | `(終値 - SMA20) / ATR` |
| 10日・20日騰落率 | `(終値 / n営業日前終値 - 1) × 100` |
| 20日変動ATR | `(終値 - 20営業日前終値) / 現在ATR` |
| 抵抗までの余地 | `(抵抗参考水準 - 終値)`を終値に対する%とATRで表示 |
| 損切り幅 | `(終値 - 採用経路の損切り目安)`を終値に対する%とATRで表示 |
| 抵抗までのR/R | `抵抗までの余地 / 損切り幅`。形状目標の実行R/Rとは別の数値 |

スイングの抵抗は60営業日、中長期は120営業日の既存の抵抗帯検出を使う。帯の手前と、当日を除く20日・参照期間の最高値のうち、現在値より上にある最も近い水準を採る。履歴が参照期間に足りない場合、その期間の最高値は使用しない。局所高値の確定に必要な後続日足は分析基準日までに存在するものに限る。

現在値が抵抗帯内なら余地は0。上方の抵抗が未検出の場合は「未検出・未算出」であり、上値余地が無限とは解釈しない。損切り目安がない、0以下、または現在値以上の場合、損切り幅とR/Rは未算出。古い保存結果に追加指標がない場合も未算出とし、0で埋めない。

これらの指標には自動的な「安全」「買い」ラベルを付けない。ATRは直近の値幅拡大でも変わるため、%とATRを併記する。狭いストップによる大きなR/Rを期待利益や勝率として解釈しない。

## スイング押し目反発

30営業日以上の履歴がある5日モードだけで評価する。中長期の70日要件や20・60日線の戦略とは別の評価器を使う。

| 条件 | 初期ルール |
|---|---|
| トレンド | SMA10 ≥ SMA20、SMA20が5営業日前より上、終値 ≥ SMA20 − 0.5 ATR |
| 支持候補 | 直近3本が始まる直前のSMA20、またはその時点までに確認済みの旧抵抗帯。中心±0.35 ATR |
| 押し目の存在 | 直近3本より前の10本に支持帯上端より高い終値があり、その10本の高値から直近3本の安値へ0.75 ATR以上戻る |
| 支持維持 | 直近3本で支持帯に接触し、接触直前の終値と直近3本すべての終値が帯下端以上 |
| 安値安定 | 当日安値が前日安値以上 |
| 反発 | 前日終値を上回る陽線かつ当日値幅の上側40%で引ける |
| 出来高 | 当日出来高が直前20本の中央値の0.8倍以上。中央値0なら未確認 |
| 追随抑制 | 支持中心から上方1.5 ATR以内、SMA20から上方2 ATR以内、3日上昇2.5 ATR以内 |

損切り目安は`min(維持した支持帯下端, 直近3本安値) - 0.5 ATR`（下限0.01）。目標は現在の抵抗参考水準。目標未算出・抵抗帯内・有効な損切り未算出・R/R 1.5未満なら購入候補にしない。

既存ブレイクが購入条件を満たすときはブレイク経路を優先する。ブレイク経路が様子見で、総合方向が上昇、押し目の全条件が成立したときに独立の押し目経路を評価する。最新の完成パターンに下降方向がある場合、または最新成立日のパターンが失敗・勢い弱化の場合は、押し目による昇格を行わない。新規購入回避も上書きしない。ブレイクの初期3日を過ぎても、新しい押し目が成立すれば評価できる。

押し目経路には既存の共通確認（データ鮮度、決算直前5日、TOPIX、相対力、現在足の出来高・窓開け、実行水準の整合性）を適用し、その後に既存の財務・保有制約・外部市場環境を適用する。過去のブレイク水準や出来高1.5倍を押し目の購入条件として流用しない。

市場・決算予定が未取得の場合の扱いは既存ポリシーを継承する。特に未取得を「安全確認済み」とは表示しない。支持帯計算のATRは分析時点の値であり、注文の約定履歴を再現するものではない。

## 保存と表示

`entry_strategy`は`breakout`（ブレイク追随）、`swing_pullback`（スイング押し目反発）、`position_pullback`（中長期押し目）。判定の成立とは独立した経路名で、保留にも表示される。未採用ならnull。

日次バッチが`entry_diagnostics`と押し目評価を候補スナップショットのJSONへ保存するため、DBスキーマ変更は不要。一覧は保存日付の指標、詳細は再分析した日付の指標を表示する。旧スナップショットの項目は再分析後に更新される。

## 検証と限界

金融計算、データ不足、抵抗帯内、抵抗未検出、押し目成立、支持割れ、安値切り下げ、反発不足、出来高不足、R/R不足、共通リスク条件、ブレイク期間終了後の再評価、失敗の非復活、APIと候補保存の受け渡しを回帰テストで確認する。

各倍率は説明可能な初期ルールであり、収益性を検証した最適値ではない。戦略の比較には銘柄群と期間を固定し、翌営業日始値からのリターン、TOPIX超過、最大逆行、損切り到達、コスト、候補数を時間順の未使用期間で測る。時系列を無作為分割しない。新しい確率出力は追加しない。

## 上抜け検出と購入条件

上抜けパターンの検出は購入条件の充足を意味しません。ブレイク追随では、
形状目標に達するまでの間に、終値で上端を超えていない抵抗帯がある場合、
購入候補を「監視・上位抵抗帯の突破確認待ち」に変更します。
抵抗帯はスイングで60営業日、中長期で120営業日を参照し、複数の局所高値から算出します。
終値が帯の上端と同値の場合も未突破です。目標以上に始まる帯は対象外です。
帯の上端を超えた後も、出来高・地合い・イベントなどの既存条件を再評価します。
抵抗帯未検出は上値余地の保証ではありません。押し目戦略の既存条件は維持します。

メイン画面では上抜け検出と購入条件を分離し、形状目標のR/R、抵抗までの余地、
抵抗までのR/Rを並べます。帯内の距離0は上昇余地がないという予測ではありません。
形状目標は5営業日以内の到達予測ではなく、損切り目安も約定を保証しません。
財務注意と決算予定未取得は候補判定の近くに表示し、未取得をイベントなしと扱いません。
スイングの財務ゲートと注意情報は[財務仕様](light-research-design.md)に従います。

保存済み一覧は再分析時に更新されます。旧エンジンの結果が残る場合は一覧に注意を表示し、
選択銘柄のメイン画面で現行ルールによる判定を確認できます。一覧の再読み込みだけでは再分析しません。

### 候補一覧と詳細の整合性

保存結果のエンジンバージョンが現行と異なる（または未記録）、あるいは資金・保有変更等で
再分析が必要な場合、または分析後に新しい日足が届いた場合・分析日が4暦日を超えて古い場合、
旧「購入候補」はAPI側で「様子見・再分析待ち」として返します。
この判定は絞り込み・ページ分割より先に行い、購入候補の件数と表示を一致させます。
フロントエンドでの警告だけに依存せず、直接APIを利用する場合にも適用します。

`reanalyze-market`は、保存済みの
株価・財務・市場環境・資金設定からスイングと中長期を再分析できます。外部データ取得や
通知送信は行いません。日次処理と同じ排他ロックを使い、結果は両期間まとめて反映します。

## TOPIX下落時の保留診断

実際のテクニカル判定が様子見で、TOPIXトレンドスコアが−10点未満の場合、
`market_gate_diagnostic`に市場下落条件だけを除いた補助診断を付与する。
元の日足、方向、相対力、決算予定、現在足、実行水準、上位抵抗帯の条件は維持し、
ブレイク追随と押し目の経路選択も同じ判定処理で確認する。

| 状態 | 意味 |
|---|---|
| `market_only` | TOPIX下落条件を除くとテクニカルの購入条件を満たす |
| `other_conditions_pending` | TOPIX以外にも条件未達がある。代表理由を併記する |
| null | 診断対象外、必要データ不足、未生成、または一覧の再分析待ち |

この診断によって実際の購入区分・スコア・株数を変更しない。
財務・資金制約・外部市場環境は診断の対象外であり、`market_only`は最終購入候補を意味しない。
表示するTOPIXスコアは元の観測に基づく値とし、仮の市場価格や確率は表示しない。

市場一覧には「技術条件：TOPIXのみ保留」の件数・絞り込み・ラベルを表示する。
詳細にはTOPIX以外の条件の代表理由を表示する。旧版・鮮度不足・資金や保有変更などで
再分析が必要な保存結果は診断を返さず、現在の条件を満たしているようには表示しない。
一覧の診断は再分析で更新され、一覧の再読み込みだけでは生成されない。
