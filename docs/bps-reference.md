# BPS参照と財務確認待ち

エンジン2.19.0から、BPSの出典と手動確認の記録を分離する。
判定は分析情報であり、資料確認の保存は購入の推奨・注文ではない。

## BPSの採用条件

- 最新決算の正のBPSを優先する。最新値がゼロ・負の場合は過去値で置き換えない。
- 最新値が欠損なら、同じ連結区分・会計基準の直近の正のBPSを参照候補とする。
- 基準日・開示日・開示番号・書類種別・元の記載値・採用状態を表示する。
  利益等の採用決算は変更せず、BPSだけに独立した出典を持たせる。
- 過去の別開示を自動参照できるのは、貸借対照表の基準日が同じで、自己資本・発行済株式数・
  自己株式数が両開示に存在して一致し、基準日からの日足・調整係数を確認できる場合だけ。
- 異なる基準日のBPSは資料確認が必要。日足の調整係数が変わらないことだけでは増減資等を
  網羅できないため、別決算期の値を自動補完しない。
- 参照元以降の赤字、修正再表示、連結区分変更、発行済株式数・自己株式数・資本金の変化、
  BPS基準日後の分割等を検出した場合は採用しない。手動確認でこの制約は解除できない。
- 分割後のBPSを独自換算することや、純資産から不足BPSを推定することは行わない。
  未採用の場合のPBRは未算出のままとする。

元データは[J-Quants財務サマリーの仕様](https://jpx-jquants.com/ja/spec/fin-summary)に従う。
空欄は開示に値がないことを示し、前回から変化がないことを保証しない。
自己株式数 `TrShFY` と会計方針変更等のフラグは今回から新規保存対象に加えた。既存開示は書き換えないため、
保存済みデータにこの項目がなければ、自動参照の条件未確認として扱う。

## 資料確認と失効

詳細画面の「BPSの参照元と確認」から根拠URL・確認内容を入力し、次の全項目を明示確認する。

1. BPS基準日から確認日までの分割・併合・増減資・自己株式の変化。
2. 連結区分・会計基準・訂正の整合性。
3. その後の損失等による純資産の重要な変化。

URLは記録のみで、自動取得・自動検証しない。資料確認は利用者の記録であり、システムが
非開示の資本変動を網羅検証したことを意味しない。資料に不確実性があれば確認待ちを維持する。
確認時は財務同期成功・株価4暦日以内を要求し、開示当日等のイベント保留中は受け付けない。
根拠・確認日・参照元・対象の最新決算・開示集合と分割等の識別値をDBの `bps_reviews` に追記する。
取消も追記し、古い確認を復活させない。

新しい開示、参照元の変更、検出した分割等の変更、参照期限変更で確認は失効する。
確認期限・BPSの基準日からの期限を過ぎても失効する。新しい決算や注意事項を
以前の資料確認で解除しない。保存・取消時は該当銘柄の保存済み候補を再分析待ちにする。
開示の追加保存でも該当銘柄の保存済み判定を無効化する。
保存済み候補一覧は確認期限をSQL絞り込み前に確認し、期限切れの購入候補を返さない。

保存後は詳細画面を再読み込みし、財務・イベント・外部環境・資金と集中度を通常どおり再判定する。
市場一覧の更新には日次処理または `docker compose run --rm app stock-signal reanalyze-market` を使用する。

| 環境変数 | 既定値 | 許容範囲・意味 |
| --- | ---: | --- |
| `BPS_MAX_AGE_DAYS` | 450 | 1〜730。BPSの基準日からの暦日数上限 |
| `BPS_REVIEW_MAX_AGE_DAYS` | 30 | 1〜90。資料確認日からの暦日数上限 |

期限当日は有効、翌日から無効。いずれも運用上限であり、収益性の検証で最適化した数値ではない。
設定変更後はAPIの再作成と市場再分析を行う。

## 候補一覧

最終購入候補と、テクニカル通過後の保留を別々に表示・絞り込みする。

| 状態 | 意味 |
| --- | --- |
| データ取得待ち | 未取得・取得失敗・同期が古い |
| 財務確認待ち：項目不足 | 計算に必要な開示項目がない |
| 財務確認待ち：比較・内容確認 | BPS参照の確認、前年同期比較、連結範囲等の確認が必要 |
| 財務・イベント注意 | 業績悪化・高PER・下方修正・開示当日等の注意がある |
| 資金・その他リスク保留 | 資金上限、外部環境等で保留 |

注意と欠損が重なる場合は財務・イベント注意を優先する。これらの区分は
テクニカル通過銘柄に対して付与し、技術条件未充足の銘柄を確認待ち候補へ昇格させない。
元の財務指標・注意理由は詳細画面に残す。確認待ちは購入候補でも将来の上昇確率でもない。
