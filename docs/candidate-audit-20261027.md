# 購入候補ゼロの再検証（2026年10月27日）

## 結論

最新日のDBと稼働中HTTP APIの両方で、スイング・中長期とも購入候補0件を確認した。
今回は表示だけの問題ではない。全件エンジン2.18.0で、前日の監査とは原因・件数が異なる。
スイングは市場一律保留、中長期はテクニカル通過後の財務確認が直接の障壁である。
特に「最新決算のBPSが必須」という設計は、開示項目の欠損を候補除外へ直結させている。
一律の閾値緩和より、欠損の扱いと戦略の対象範囲を先に見直すべきである。

この資料は分析システムの監査であり、記載銘柄の購入推奨ではない。
本番の判定条件、保存済み分析、保有情報は変更していない。

## 1. スイング：相対的に強い銘柄も市場条件で一律保留

保存TOPIXの20営業日騰落率は−2.788%、市場点数は−13.9。
現行の市場点数−10未満による保留は、スイングでは概ね20営業日騰落率−2%未満に対応する。
ブレイクと押し目の両経路に適用される。

保存済み `market_gate_diagnostic` では、市場条件だけを除外すると他のテクニカル条件を
通過する `market_only` が12件。財務・イベント・資金・外部環境を含む最終候補数ではない。
市場保留を最初の理由として返す124件（ブレイク97件、押し目27件）の全てが通過するわけではない。

弱い相場で新規エントリーを抑える設計としては整合するが、市場より強い銘柄を拾う経路がない。
「市場条件を緩めれば成績が向上する」ことは未検証。市場相対力・業種相対力・市場回復を
条件とする別経路を設け、既存経路と時系列で比較するのが検証対象となる。

参照：`analysis/decision.py`、`analysis/horizons.py`、`analysis/engine.py`。

## 2. 中長期：テクニカル通過10件を財務条件で全件保留

TOPIXの60営業日騰落率は+0.852%。中長期のゼロは市場一律保留によるものではない。
テクニカル通過10件の財務同期は全件 `success`。取得失敗や古い同期が直接の理由ではない。
しかし最新決算のBPSは全10件で空欄。過去のBPSはあるが代用せず、PBRが未算出になる。

| 財務上の保留理由 | 件数 | 対象コード |
| --- | ---: | --- |
| BPS欠損だけ | 2 | 5576、6907 |
| BPS欠損＋連結範囲変更等の確認 | 2 | 3562、8022 |
| BPS欠損＋前年同期比較不可・前年営業赤字等 | 2 | 5028、9563 |
| BPS欠損に加え業績悪化・高PER等の注意 | 4 | 2224、6277、7422、8052 |

7422には直近30日以内の営業利益予想下方修正もある。
「BPS対応だけで10件が購入候補になる」とは言えない。
5576・6907もBPSの妥当な確認後に資金・集中度等を再判定する必要があり、最終通過は未確定。

財務判定は、営業利益・純利益、売上高と営業利益の前年同期比、予想PER、PBR等が揃うことを
`reviewed` の前提とし、中長期は `reviewed` 以外を一律保留する。
PBRに上限を置くのではなく、PBRを算出できること自体が必須条件になっている。

保存済み財務の最新決算505銘柄を別途集計すると、BPS欠損は375銘柄。
内訳は1Q 250、2Q 85、3Q 40。本決算43銘柄では全件BPSが存在した。
これは取得済み505銘柄に限る観察であり、全市場の欠損率ではない。

[J-Quants公式仕様](https://jpx-jquants.com/ja/spec/fin-summary)では、開示書類に記載のない項目は
空文字列であり、前回からの変更の有無を意味しない。したがって、空欄を業績不良と同一視することも、
過去値を無条件に最新値として引き継ぐことも適切ではない。

改善案は、利益等のフロー情報と純資産等のストック情報の採用日を分離し、
過去BPSの使用可否を分割・増減資・連結区分・基準日・鮮度から検証すること。
確認できない場合はPBR未算出を維持し、「テクニカル通過・財務確認待ち」を独立表示する。
最新BPSの欠損を単に無視して購入候補へ昇格させる対応は、今回の検証からは正当化できない。

参照：`fundamentals.py:evaluate_financials`、`research.py:enrich_analysis`。

## 3. 考慮漏れ・追加で見直す設計

1. **中長期の対象が狭い。** 実体は中期上昇トレンド内の押し目である。
   20日線と60日線の順序、60日線の上向き、支持帯接触、当日反発、出来高または反発継続、
   相対力、損益比1.5以上を組み合わせる。企業価値・配当・業績回復による独立した候補生成はない。
   20営業日先の評価を、年単位の長期投資判断と同一視できない。
2. **終了した下降パターンが後続の押し目評価を遮断する。** 失敗・弱化・目標到達・期限切れでも
   `_decide` が早期に `WATCH` を返す。理由文の「現在のテクニカル要因で判断し直す」と実際の
   制御にずれがある。スイングも下降パターンの存在で押し目への切替が制限される。
   現在有効な下降を維持しつつ、終了済みパターンと新しいセットアップを分離する改善対象。
   今回はこの変更による最新日の増加件数を再計算していない。
3. **新高値の評価経路がない。** 過去の抵抗が見つからない場合は目標未算出となり保留される。
   架空の目標を補うのではなく、新高値追随を別戦略として検証する必要がある。
4. **業種・回復局面の違いを十分扱わない。** 営業利益の比較とPER40倍を業種横断で用いる。
   前年営業利益がゼロ以下では増減率未算出となるため、黒字転換も追加確認に止まる。
   銀行等の業種固有指標や回復戦略を別途定義しなければ、網羅的な候補探索にはならない。
5. **財務欠損の母数に注意。** 最新の中長期3,624件中、財務 `missing` は3,125件、
   `reviewed` は2件。ただしバッチはテクニカル通過銘柄を優先同期する設計であり、
   3,125件が全て取得障害で落ちたという解釈は誤り。今回の通過10件は同期済み。
6. **鮮度の暦日基準。** テクニカル7日、一覧・財務統合4日という差があり、
   大型連休で不必要な保留を生み得る。今回の最新日分析ゼロの原因ではない。

中長期の最初の保留・回避理由には下降パターン1,265件、トレンド不成立705件、
反発待ち375件、上値余地不足148件がある。条件は順番に評価するため、
これらは独立条件ごとの全不合格件数でも、条件を外した場合の増加件数でもない。

## 優先順位と検証の限界

最優先は財務確認待ちの可視化と、BPSの参照時点を扱う設計。
次に終了済み下降パターンの経路遮断を修正し、市場一律保留の例外・新高値・長期企業価値の
各経路は別戦略として評価する。損益比や出来高の閾値を一括緩和する根拠は得られていない。

単日の原因とコード上の偏りは確認したが、閾値の最適性や戦略の収益性は今回判定していない。
比較には時間順の未使用期間、取引コスト、重複イベント、相場局面、過去時点の財務情報が必要。
既存 `strategy-study` は財務・資金・過去決算予定を含まないため、今回の財務条件の有効性を
その成績だけで検証することはできない。
