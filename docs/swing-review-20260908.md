# スイング購入候補の再点検（2026年9月8日）

## 対象と結論

保存済み候補は3349コスモス薬品、6770アルプスアルパイン。基準日足は9月7日であり、9月8日の日中相場を評価したものではない。両銘柄で9月3日の上抜けと出来高を使い続け、現在足の売り圧力・上抜け水準への戻りを購入区分へ反映できていなかった。前回2.10.0の修正は構造的な失敗・目標到達・窓開け等の確認にとどまり、この条件を見落としていた。

## 実装した修正（2.11.0）

スイングが従来の購入候補条件を満たした場合にも、以下なら様子見に戻し、具体的な理由を分析チェック・理由・注意事項へ残す。

1. 現在終値が採用した上抜け水準以下。
2. 現在足が陰線で、終値が当日高安の中央より下。

これは「下落が確定した」という分類ではなく、ブレイク追随に必要な現在の確認が不足しているという保留。中長期の押し目ルールにはこの条件を一律適用しない。陽線・上抜け維持の場合は従来の他条件で判定する。銘柄コードによる例外はない。

1はブレイク追随の論理的整合性の修正。2は売り圧力のある足で追随しないための保守的な設計判断で、中央50%を最適値とする実証結果はない。単独のローソク足に予測力があるとも、今回の2銘柄を外せば運用成績が上がるとも主張しない。実行用ストップが触れたかという売買履歴と、形状の構造的な失敗は別途扱う。

## 残る重要な改善候補

### 損益比が大きく見える問題

旧判定の実行用リワード／リスクは5.78、6.71だった。しかし現在値からストップまでの距離はそれぞれ約105.20円（現在ATR195.98の0.54倍）、33.76円（ATR66.69の0.51倍）しかない。構造的無効化ではなく、上抜け水準の0.5 ATR下を使うため、日常的な値動きで触れ得る浅いストップが比率を押し上げる。

これだけで5.78倍・6.71倍が算術的に誤りとは言えないが、期待収益の大きさとは同義ではない。概念上の期待損益は「勝率×平均利益－敗率×平均損失－コスト」。未検証の目標値と狭いストップの比率から勝率を推測してはならない。ストップ価格での約定も保証されない。

次は構造的ストップ・0.5/1.0/1.5 ATRの候補を同じ時系列で比較し、コスト控除後損益と損切り到達率を確認する。一律にストップを広げる変更は、損失額や適切な株数も変えるため今回は採用しない。

### 上抜け形状と目標の定義

現在の価格帯上限は30日高値の90パーセンタイルであり、直近最高値そのものではない。したがって、高値を更新せずに上抜け検出される場合がある。また、接触回数は独立した反転の回数ではなく、その帯に近い日足の本数。日次の傾き許容幅も30日を通じた大きな傾きを許容し得る。

これは機械的な帯の検出としては定義可能だが、教科書的な水平レクタングルと同等の精度とは扱えない。独立した複数接触、形成全体のATRに対する傾き、直近高値を抵抗として残す方式を比較する必要がある。

形状の高さによる今回の目標は7,256円と2,483円。これらは幾何学的な延長値で、5営業日内の到達予測ではない。途中の抵抗帯と、期限内の実現可能性を別々に評価すべきである。

### 検証方法

今回の2銘柄だけを使って閾値を調整しない。改修前後を同じ期間・同じユニバースで比較し、5日・20日後のTOPIX超過、最大逆行、損切り到達率、コスト、候補数を確認する。時系列を無作為分割せず、検証に使わない後続期間も確保する。テクニカル形状の統計的な情報と、そのまま利益になる売買戦略は区別する。
